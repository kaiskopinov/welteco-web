Square 46px icon button for the nav info button and "Learn More →" arrow tiles.
```jsx
<Component7 icon1={<Icon name="info" />} />
```
- 46×46 off-white icon button, radius 6, sand border; icon1 swaps the glyph. Hover: opacity 0.5.
- Hover follows the pointer; pass `hover` to force a state. `block` stretches to full width; `href`/`onClick` make it interactive.
