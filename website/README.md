# Welteco website

Static site for Welteco, official representative of ORU (IMER Group, Italy) in Ukraine. Built in Claude Design as Design Components (`*.dc.html`); each page opens directly in a browser (`support.js` is the runtime).

## Pages
- `Home B Amber.dc.html`: home page
- `About.dc.html`, `Partners.dc.html`, `Machines.dc.html`, `Product.dc.html?id=…`, `Product Examples.dc.html`, `Contacts.dc.html`, `Site Under Update.dc.html`
- Shared: `Site Header.dc.html`, `Site Footer.dc.html`, `Contact Block.dc.html`
- Content: `content.js`, `site-content.js` (UA + EN)
- Explorations: `Home A/B/C`, `Home B Blue`, `Welteco Home Options`, `Welteco Current`

Serve the folder with any static server (e.g. `npx serve website`) and open `Home B Amber.dc.html`.
